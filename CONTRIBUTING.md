# 🤝 Contributing to Fils_Incubator_Project

Thank you for considering contributing to this project! Follow the guidelines below to ensure a smooth collaboration.

## **1️⃣ How to Contribute**
✅ Fork the repository  
✅ Create a feature branch (`git checkout -b feature-name`)  
✅ Make changes & test functionality  
✅ Submit a pull request with details on modifications  

## **2️⃣ Code Formatting**
- Use **Python 3.9+ syntax**.
- Keep JSON files **structured & documented**.
- Follow PEP-8 **coding standards**.

## **3️⃣ Issue Reporting**
If you encounter issues:
1. **Check `troubleshooting.md`** for common fixes.
2. **Create an issue** on GitHub with relevant logs/screenshots.
3. **Suggest improvements** if applicable!

🚀 **Happy coding!** 🐣
